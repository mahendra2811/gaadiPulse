# Asset source and integration

`assets/` is the app's checked-in asset source. There is no separate artwork mirror or asset-copy command. Keep Metro image references static so the Android bundle can resolve them.

Runtime artwork is limited to the 43-image subtype registry, onboarding and sign-in illustrations, the current logo variants, and the reports banner. Launcher, favicon, adaptive foreground and notification images are generated by `node scripts/build-brand-assets.mjs` from `assets/media/logo/new/`.

`assets/vehicle-subtypes/index.ts` is the static registry used by the selector and vehicle cards. `vehicle-catalog.v2.json` supplies its labels and categories. Unknown saved subtype IDs fall back to `other`.

The illustrations are product-agnostic artwork, not vehicle make/model photographs. User receipts and vehicle photo uploads are not part of the current app. Subtype pack provenance is documented in `assets/vehicle-subtypes/README.md`.
