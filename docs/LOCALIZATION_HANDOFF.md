# Localization implementation handoff — 2026-11-28

## Implemented

- `src/lib/i18n/locales/en.json` remains the sole English source catalog; it currently contains 1,309 strings.
- Added `src/lib/i18n/locales/registry.json` as the single registry for all 45 app-selectable languages, catalog paths, native names, direction, and translation status.
- Runtime lookup falls back to English for unknown locale codes and missing or blank translation values. Profile validation, onboarding and Settings choices, and Expo native localization language codes derive from the registry.
- Added static imports for all 45 catalogs. Hindi now has 1,309/1,309 populated strings and is marked complete; the other 43 catalogs remain partial and display English for unfinished copy.
- Added active-locale date, number, and money formatters. Stored ISO timestamps and integer minor-unit amounts are unchanged.
- Added `scripts/check-locales.mjs`, `npm run i18n:check`, `npm run i18n:check:required` for English/Hindi, strict all-language `npm run i18n:check:complete`, and focused fallback, registry, formatting, and direction tests.
- Expanded the locale README with key/section/locale workflows, incomplete-catalog rules, validation commands, and RTL release requirements. Recorded the registry decision in `docs/DECISIONS.md`.

## Translation coverage and remaining work

`npm run i18n:check` reports 1,309 English keys. Hindi has 1,309 populated strings and zero blanks. Spanish, French, German, Italian, and Dutch currently have 49 populated strings each and use English fallback for the remainder. The other 38 non-English catalogs currently have 0 populated strings. The incomplete catalogs remain partial. The README checkboxes represent completion, not selectability. The all-language strict completion command intentionally fails while any other locale remains partial.

RTL direction is represented in registry metadata and exposed by `getLocaleDirection()`. RTL languages are selectable, but native/web RTL layout is not implemented or device-verified. Complete that wiring and device QA before treating an RTL locale as release-ready.
