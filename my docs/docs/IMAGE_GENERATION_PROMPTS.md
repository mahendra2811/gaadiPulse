### Image QA checklist
- All assets have readable scale at ~120dp.
- No AI-produced fake words/registration plates/official logos.
- Same light direction and stroke style across onboarding set.
- No identifiable person, vehicle plate, or private data.
- Export for launcher Android compliant icon-safe area; vector path if icon editability is needed.
